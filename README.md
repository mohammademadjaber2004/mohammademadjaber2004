## 📂 Featured Projects

### [TransLogix Shipment Delay Analytics](https://github.com/mohammademadjaber2004/translogix-shipment-delay-analytics)
Big data analytics on **100K shipments** using **PySpark** and **Power BI** to predict delivery delays.  
Built end-to-end pipeline: data cleaning, feature engineering, Spark ML models (Linear Regression, Random Forest, GBT), and interactive dashboard.  
**Tech:** Python, PySpark, Power BI, Spark MLlib

### [Gallstone Disease Prediction — ML & Explainability](https://github.com/mohammademadjaber2004/gallstone-disease-prediction)
Binary classification of gallstone disease using **4 ML models** with **SHAP and LIME** explainability.  
Compared Logistic Regression, SVM, Random Forest, and KNN. Random Forest achieved best F1-score (0.79).  
**Tech:** Python, Scikit-learn, SHAP, LIME

### [Supply Chain ML — Late Delivery & Profit Prediction](https://github.com/mohammademadjaber2004/supply-chain-ml)
Predicted late delivery risk and order profit on **180K+ orders** using **KNN, Linear Regression, and ANN**, plus Azure ML rebuild.  
ANN achieved 69% accuracy (vs. 59% for KNN). Linear Regression explained 73% of profit variance (R² = 0.73).  
**Tech:** Python, Scikit-learn, Keras, Azure ML Studio
